
# Bases de Dados — Projeto 01

Esta pasta contém os arquivos Excel utilizados durante o desenvolvimento do Dashboard Gerencial de Suprimentos.

## Arquivos

- CADASTRO_FORNECEDORES.xlsx
- PEDIDOS_AULA_01.xlsx
- PEDIDOS_AULA_02.xlsx
- PEDIDOS_AULA_02_PARTE 02.xlsx

## Observações

Todos os dados são fictícios e utilizados exclusivamente para fins educacionais.

Os arquivos incluem bases de exercícios e fontes de dados usadas nas etapas de importação, transformação e consolidação no Power Query.

Para atualizar o dashboard em outro computador, pode ser necessário configurar novamente os caminhos das fontes no Power BI Desktop.
